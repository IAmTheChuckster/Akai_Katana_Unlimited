A gameplay patch for Akai Katana (2010/ 8/13 MASTER VER.)<br>
This repository holds only source, tools and notes. **No ROM data is included**; you patch your own legally owned dump.

## About this project
Why did I make this? Because it's fun and for my own personal research to see the capabilities of Claude.<br>
While Claude was used I put effort in making sure there are balanced gameplay.<br>
I did all the testing and planning.

## Change Notes

### Kiwami branch (work in progress, u4 CRC32 `ee4f0c6a`)
- **Enemy bullets come in threes (UNLIMITED).** Every normal enemy bullet is followed by two copies on the same path, 5 and 10 frames behind, so each shot becomes a trailing line of three. Revenge bullets stay single. (Wrapper on the bullet-create calls at `0C1FFBB4`/`0C1FFCD4`.)
- **Enemies fire 1.5x as often (UNLIMITED).** Every other enemy volley is fired a second time 20 frames later, from the same spot with the same pattern. (Replay queue in front of the shot-emitter processor, pointer at `0C1FF38C`; queue in RAM at `0C7F2000`.)
- **Fixed the stage 1 boss freeze** ("enemy/enemy.cpp" error screen with the music still playing). The game keeps its enemy objects in a fixed pool of 999 memory blocks; the original game already uses up to 784 of them at the stage 1 boss, and the extra bullets pushed it over. The pool is moved to unused RAM at `0CD00000` and enlarged to 2,400 blocks (in-use table at `0CD26000`), in both modes.
- Extra bullets and repeated volleys pause while more than 900 enemy bullets are on screen, so the game's own 999-bullet cap is never hit.
- ARCADE MODE is otherwise unchanged.

### 2026/10/22 (u4 CRC32 `7f51bcd6`)
- New mode menu: after a coin is inserted, the title screen shows **ARCADE MODE** and **UNLIMITED** in place of the rank and high-score lines. Move the arrow with up/down and press start. ARCADE MODE plays the original, unmodified game; UNLIMITED plays with all the changes below. The choice is remembered until power-off (default ARCADE MODE).
- Removed the revenge bullets that were fired together with enemies' normal shots in ship mode. Revenge bullets are back to the original: destroyed enemies fire them in spirit form only.
- Energy balls that circle you in spirit form are now collected automatically when you go back to ship mode, instead of returning to the orb.
- New warning screen: an unofficial-project notice and "HAVE FUN!!!" (Japan and export versions).
- Version line on the warning screen now reads `2026/10/22 UNLIMITED`; the memory-check screen reads `AKAI KATANA UNLIMITED` / `2026.10.22`.
- Web patcher: renamed to Akai Katana Unlimited (outputs `akatanaultd.zip` and `Akai Katana Unlimited.mra`), the Changes section was removed, and the source link points to this repository.

### Current features

- **Mode select.** ARCADE MODE / UNLIMITED menu on the title screen once a coin is in (permanent hook at `0C221F30`; the mode is applied at game start through the scene-change hook, writing either the UNLIMITED values or the original values listed in `src/goldpatch.s`). Everything else in this list applies in UNLIMITED only, except the boot screens.

Spirit form = 念身.

- **Gold is collected automatically.** Gold no longer circles the ship until spirit form ends. As soon as a piece has a player to fly to, it goes to the release state and is collected.
- **HIT counts collected gold.** The +1 HIT now happens when a gold piece is collected, not when it spawns.
- **HIT resets each stage.** The game's own clears (3 seconds after the last hit) are disabled, so HIT keeps counting through a stage; it goes back to 0 when a game starts and when the next stage begins (scene change at `0C1F0E10`).

- **Leaving spirit form early is free.** Pressing the spirit button again used to cost a flat 1,600 energy; now you keep what you have left.
- **Warning screen:** the boot warning now reads the unofficial-project notice and "HAVE FUN!!!", and the version line reads `2026/10/22 UNLIMITED`; the memory-check screen reads `AKAI KATANA UNLIMITED` / `2026.10.22` (both the Japan and export versions; text generated by `tools/warntext.py`, copied over the original strings at boot).
- **Revenge bullets:** as in the original game. Destroyed enemies fire them in spirit form only.
- **Bullets slow down near the orb.** Enemy bullets within 24 px of the orb (the familiar ball, whose live position is at `0CA3FBB4`/`0CA3FBB8` for every character) move at half speed, and return to full speed as soon as they leave. This applies in ship and spirit form. It uses the game's own per-bullet slow percentage (bullet+0x138), which the bullet move code applies as velocity × (100 − slow) / 100.
- **Energy balls follow you into spirit form.** Energy balls (item kind 12) circling the orb are no longer sent to be collected when you switch to spirit form. They circle the hitbox instead, the way gold used to (radius about 50 px widening to about 78 px), and are collected automatically when spirit form ends. Their lifetime (item+0xB4; they normally expire about 510 frames after appearing) is paused while you're in spirit form.

- **Close-range medals.** A 100 medal that appears within 50 px of your hitbox (for example from an enemy you destroy up close, or bullets cancelled next to you) becomes a 1,000 medal. Boss gold is still a 10,000 medal.
- **Gold is worth medal × HIT ÷ 10.** Each gold piece collected scores 10% of its medal value (item+0x50: 100 / 1,000 / 10,000) × the HIT count (including this piece). The value is written back into the item before it is added, so the gold score total (`0C27B670`) and the trailing popup (`0C22A320`) show the same amount. Example: a 1,000 medal at 359 HIT adds 35,900.
